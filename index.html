E-PR Portal: Procurement Tracker

A web portal for tracking purchase requests from request to approval, with supplier, item and user management. The 2022 original ran on AWS behind a load balancer, with an EC2 web server, RDS MySQL, ACM TLS and a Route 53 domain. In 2026 I rebuilt it as a responsive PHP/MySQL app and redesigned the AWS architecture in Terraform: ECS Fargate across two Availability Zones, RDS MySQL in private subnets, Secrets Manager, and an ALB with ACM and Route 53. GitHub Actions tests every push and deploys through OIDC, with no stored AWS keys.

Thesis

Smart Grid: IoT-Based Counter Fluctuation Control for Power Distribution

A home power-distribution panel that monitors voltage and current on each circuit in real time. An Arduino Nano reads the voltage sensor and current clamps, and a Raspberry Pi stores the readings in MariaDB. The Pi switches off any circuit that goes over its limit through solid-state relays and contactors, and sends email alerts. A Node-RED dashboard, later hosted on an Azure VM, shows live gauges, logs and calibration. Rated "Highly Acceptable" (3.63/4) by 25 evaluators. I have since redesigned it on Azure: protection stays on the Pi, and readings go over MQTT/TLS to Azure IoT Hub, with Node-RED dashboards running on Azure Container Apps, history in Azure Data Explorer, and Logic Apps for email and SMS alerts.
